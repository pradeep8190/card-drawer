# 🃏 Card Drawer — Tactile 3D Cards & Drawer UI

[![JavaScript](https://img.shields.io/badge/JavaScript-ES6+-yellow?style=flat&logo=javascript)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
[![CSS3](https://img.shields.io/badge/CSS3-3D_Transforms-blue?style=flat&logo=css3)](https://developer.mozilla.org/en-US/docs/Web/CSS)

> Fluid, tactile 3D card drawer and stacking interaction component. Built with hardware-accelerated CSS transforms and smooth spring animations.

---

## ✨ Features

- **3D Card Elevation**: Perspective-correct hover and drag elevation.
- **Smooth Drawer Kinematics**: Elastic drawer pull-out and snap behavior.
- **Zero Dependencies**: Pure HTML5, CSS3, and JavaScript.

---

## 🚀 Quick Start

```bash
git clone https://github.com/pradeep8190/card-drawer.git
cd card-drawer
# Open index.html directly in any browser
```
